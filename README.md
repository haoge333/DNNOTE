# 龙之谷小助手

龙之谷怀旧服副本进度管理工具：按周记录账号/角色的副本通关情况、设置悬赏、统计通关与分红收益。离线运行，数据保存在本地。

- 平台：Windows 10 / 11（Tauri v2 + WebView2）
- 形态：绿色免安装，双击 exe 即用，无联网、无登录

---

## 一、快速上手

1. 把 `龙之谷小助手.exe` 放到任意目录（建议单独建一个文件夹，数据文件会生成在同目录）。
2. 双击运行。首次启动会自动生成空数据文件。
3. 按顺序完成初始化：
   - **管理 → 副本管理 → ＋ 新增副本**：填写副本名、人数、悬赏优先级（高/中/低），决定是否启用。
   - **管理 → 账号管理 → ＋ 新增账号**：填写账号名。
   - **管理 → 角色管理 → ＋ 新增角色**：选择所属账号、职业/二转、等级，并勾选该角色**可通关的副本**。
4. 回到**总览**，点击角色行与副本列交叉的方框即标记本周通关；再次点击取消（会二次确认）。

> 角色未勾选「可通关副本」时，总览对应格子为虚线不可点。

## 二、页面说明

### 1. 总览

| 操作 | 说明 |
| --- | --- |
| 点击方框 | 标记/取消本周通关；取消时弹窗二次确认 |
| 搜索角色名 | 按角色名过滤 |
| 全部账号 | 只看某个账号 |
| 显示已归档角色 | 归档角色默认隐藏 |
| 显示已停用副本 | 停用副本默认不显示，显示时不可勾选 |
| 周下拉框 | 查看历史周；历史周**只读**，不可修改通关记录 |
| 全部展开 | 展开/折叠账号分组 |
| 手动重置本周 | 清空本周勾选，进入新的一周（历史周数据保留） |

角色名下方的悬赏标签：

- 点击该区域打开悬赏设置：勾选本周要打的副本，并为每个副本选择等级 **L / S / A / B / C**。
- 可标记「同公会」「限时」。
- 完成数显示为 `已完成/总数`，全部完成时标签变绿。

### 2. 管理

- **账号管理**：新增/编辑/删除账号。删除账号会连带删除其下所有角色与通关记录。
- **角色管理**：
  - 新增/编辑角色：所属账号、0 转职业、二转职业、等级、可通关副本。
  - 「归档」：隐藏但不删除，数据保留，可随时恢复。
  - 删除角色会连带删除其通关记录。
- **副本管理**：新增/编辑副本（名称、人数、悬赏优先级、启用状态）、调整顺序、删除。删除副本会清除所有角色对它的可通关配置与历史记录。
- **职业配置**：管理职业与二转职业、颜色；「恢复默认职业」会重置为怀旧服默认职业表。

### 3. 统计

顶部可切换查看的周，并提供 5 个维度：

| 维度 | 内容 |
| --- | --- |
| 按账号 | 各账号通关情况汇总 |
| 按角色 | 各角色通关情况 |
| 按副本 | 各副本被通关的人数/次数 |
| 角色收益 | 每个「我的角色」的收益：所选周收益、其中分红、其中出货、已收、待收、累计收益、次数 |
| 账号收益 | 按账号汇总上述收益 |

- 收益 = 分红所得 + 出货所得；分红含待分红，**未售出的分红物品不计入**。
- 所选周收益最高的角色显示金色 **运气王**，最高的账号显示紫色 **欧皇**。
- 切换周后称号随之重新计算。

### 4. 分红

用于记录副本产出的高价值物品，卖出后把金币分给队友。

**记录一笔产出**（右上角「＋ 记录产出」）：

1. 选择副本与通关日期。
2. **产出物品**：每件物品一行
   - 物品名称、封印个数（该物品需要几个封印才能交易）
   - 售价：登记时可以先留空，卖出后再填；售价大于 0 时自动记录当天为售出日期
   - 可点「＋ 添加物品」登记同一次掉落的多个物品（相同物品掉多件就加多行）
3. **分红成员**：第一行为「我的角色」（必须选择一个角色），其余为队友；默认 2 个队友位，可点「＋ 添加分红队友」继续加
   - 未填写名字的队友行会被自动忽略，不计人数
   - 勾选「拿物品」表示由该成员垫付封印费，分红时会把垫付的封印费还给他
4. 售价填入后（登记时或之后改价）会**自动均分**并填入每人分得金额：净额 = 已售收入 − 封印成本，按有效人数平分；除不尽的余数和垫付封印费归「拿物品的人」，差额提示会显示「已对齐」。
   - 想重新分配可点「均分净额」，或直接手动修改每人金额（未对齐时需勾选「允许按当前差额保存」，例如有人放弃分红）。
5. 合计与应分不一致时，需要勾选「允许按当前差额保存」（例如有人放弃分红）。

**列表操作**：

- 点参与人标签（如 `队友A 待付`）可在「已分红」与「待付」之间切换。
- 点物品金额或「未售出」可直接修改卖出价格和售出日期（快速改价），保存后会自动按新金额重新均分并填入每人分得。
- 「编辑」修改整条记录，「删除」需确认。
- 页面顶部有汇总（已售收入、封印成本、可分红净额、已分红、待分红、未售出）与「我的收益」表（已收/待收/累计已收/垫付封印）。

### 5. 出货

记录自己（不参与分红）的出货收益，用于统计哪个角色/账号赚得多。

- 右上角「＋ 记录出货」填写：账号、角色、物品名称、出售价格、出售时间。
- 出货时间用于归属周：按设置的每周重置规则自动算出属于哪一周。
- 列表可按周查看、按物品/角色/账号搜索，支持编辑与删除（删除需确认）。
- 页面顶部汇总：本周出货件数、本周收益、累计收益、最高单价。
- 出货收益会并入「统计 → 角色收益 / 账号收益」，与分红收益合并计算称号。

### 7. 设置

| 分区 | 说明 |
| --- | --- |
| 重置设置 | 每周重置的星期与小时，默认**周六 9:00** |
| 等级配置 | 新建角色时的默认等级与等级上限 |
| 封印设置 | 封印单价（金币/个），默认 5；分红时按此单价扣除封印成本，已保存的记录沿用记录时的单价 |
| 启动设置 | 开机自动启动开关 |
| 当前数据预览 | 账号/角色/副本/职业数量、当前周、各项配置、分红记录条数 |
| 导出备份 | 导出完整数据快照（包含个人数据与固定数据）到指定路径 |
| 清理数据 | 清空账号、角色、副本、通关与分红记录，设置恢复默认；**固定数据（职业表）保留** |

右上角 🌙 可切换深色模式。

## 三、周与历史

- 默认每周六 9:00 自动进入新的一周（周 ID 形如 `2026-W45`），可在设置里改。
- 总览顶部显示当前周 ID 与距离重置的倒计时。
- 切换周查看历史时，通关记录**只读**；分红记录不受此限制，可补录或修改。
- 「手动重置本周」会立刻清空本周勾选并进入新周，历史周数据保留，操作前请确认。

## 四、数据文件

程序同目录下有两个 JSON 文件：

| 文件 | 内容 | 归类 |
| --- | --- | --- |
| `龙之谷数据.json` | 当前周、副本、账号角色、通关记录、悬赏、分红记录、出货记录 | 个人数据 |
| `龙之谷固定数据.json` | 全部设置（重置时间、等级、封印单价、开机自启）与职业表 | 固定数据 |

说明：

- 所有修改在操作后约 0.5 秒自动保存，左下角会提示「已自动保存」。
- 文件夹里可以手动复制这两个文件做备份；「导出备份」则会生成一份包含两者的完整快照。
- 个人数据含账号与收益信息，分享/上传仓库前请勿包含 `龙之谷数据.json`（本仓库的 `.gitignore` 已排除）。
- 若数据文件损坏导致读取失败，程序不会覆盖原文件，而是以空白视图启动并提示错误，可先备份/修复文件再重试。
- 「清理数据」只清个人数据，设置与职业表保存在固定数据文件里，不受影响。
- 固定数据文件损坏或删除时，程序会用内置默认值重建（设置与职业表回到默认状态）；需要保留自定义设置时请先备份该文件。

## 五、从源码编译

环境要求：

- Rust（含 cargo）：https://rustup.rs/
- Windows 10/11（WebView2 运行时系统自带）

编译：

```powershell
cd tauri-app/src-tauri
cargo build --release
```

产物：`tauri-app/src-tauri/target/release/dn-dragon-nest.exe`

也可以使用 `tauri-app/build.bat`（基于 tauri-cli 1.x 的一键脚本）。

项目结构：

```text
tauri-app/
├─ src/index.html          # 全部界面与业务逻辑（单文件）
├─ src/assets/             # 背景图与赞赏码
└─ src-tauri/
   ├─ src/main.rs          # 文件读写、开机自启等命令
   ├─ tauri.conf.json
   └─ icons/
```

## 六、常见问题

**Q：第一次打开是空白的？**
首次运行会生成空白数据文件，请先到「管理」页添加副本、账号和角色。

**Q：数据放在哪？换电脑怎么迁移？**
数据在 exe 同目录的两个 JSON 文件里，把 exe 与两个 JSON 一起复制到新电脑即可。

**Q：为什么取消通关勾选要二次确认？**
避免误点导致当周进度丢失。

**Q：分红金额为什么有差额提示？**
应分 = 净额 + 拿物品者垫付的封印费。手动改过某个人的金额后合计会对不上，确认无误（如有人放弃分红）就勾选「允许按当前差额保存」。

**Q：未售出的物品能分红吗？**
不能。只有填了售价的物品才计入已售收入；未售出的只做展示，卖出后可在列表点击金额补填。
